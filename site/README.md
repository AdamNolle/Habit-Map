# Habit Map site

Static product preview for the in-development Habit Map app. Open `index.html` directly or serve this directory with any static server. It uses no external runtime dependencies or analytics.

The heatmap and Today composition are illustrative web art, not app capture or a functioning web version. `assets/insight-snapshot.png` is copied from the repository's native component snapshot test and displays example test data. The marketing copy was checked against `TodayView.swift`, `PageContentView.swift`, `MapView.swift`, `InsightsView.swift`, and the design tokens. This page does not advertise an app download or TestFlight release.

No external photos, icons, fonts, music, or footage are used. The icon, web compositions, motion graphics, and synthesized score were authored for this site. The embedded 34-second motion preview is labeled as illustrative throughout, and its native component test snapshots are labeled as example data. It is not a recorded feature demo; verified iOS/iPadOS capture is still required for that.

## Design contract

- **Purpose:** explain the gentler tracking premise and route interested visitors to the project while the app is in development.
- **Art direction:** the native dark canvas, acid green completion cells, and editorial serif type become an atlas of days. A growing pattern is the visual anchor rather than a simulated device screenshot.
- **Reference roles:** Design UI's precision-software study informed the clear feature sequence; its editorial study informed scale and quiet issue labels. The pixel calendar motif is taken from Habit Map itself.
- **Typography:** system sans for utility/reading, Georgia for expressive display, system mono for atlas labels. No external font license is assumed.
- **Composition:** opening manifesto, Today, Atlas, Reflection, then the GitHub action. Wide layouts use adjacent copy and art; narrow layouts stack without shrinking core text.
- **Media:** original CSS/SVG compositions and one source-owned test snapshot, clearly marked as example data.
- **Motion:** no required entrance animation or automatic video. The video is opt-in with controls, a poster, captions, and transcript. The page remains fully usable with reduced motion and scripting disabled; JavaScript only fills decorative cell patterns.
